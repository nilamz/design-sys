<task type="auto">
  <name>Task 1: Create barrel export and library build configuration</name>
  <files>src/index.ts, tsconfig.lib.json, vite.config.ts</files>
  <action>
1. **src/index.ts** — Replace the placeholder comment with re-exports of all 16 components and their public types. Export components and types from each component's index.ts barrel. The full list:

Components (default/named exports):
- Alert, Badge, Button, Card, Checkbox, Chip, FieldGroup, Input, PriceAlertCard, Progress, RadioButton, RideMap, Skeleton, Switch, Tabs, Toast

Types (export type):
- CheckboxProps (from Checkbox)
- FareBreakdown (from PriceAlertCard)
- RadioButtonProps (from RadioButton)
- LatLng (from RideMap)
- SwitchProps (from Switch)
- Tab, TabsProps (from Tabs)

Each line should be: `export { ComponentName } from './components/ComponentName';` and `export type { TypeName } from './components/ComponentName';`

Do NOT add a CSS import in index.ts — consumers will import CSS separately via `import '@truf/design-system/styles'` (configured in package.json exports).

2. **tsconfig.lib.json** — Create a NEW tsconfig specifically for library declaration emit:
```json
{
  "compilerOptions": {
    "target": "es2023",
    "lib": ["ES2023", "DOM", "DOM.Iterable"],
    "module": "esnext",
    "moduleResolution": "bundler",
    "jsx": "react-jsx",
    "declaration": true,
    "declarationDir": "dist",
    "emitDeclarationOnly": true,
    "skipLibCheck": true,
    "erasableSyntaxOnly": true
  },
  "include": ["src"],
  "exclude": ["src/**/*.test.tsx", "src/**/*.stories.tsx", "src/App.tsx", "src/main.tsx"]
}
```

3. **vite.config.ts** — Add a `build` section for library mode. Keep the existing dev/test config working. Add build config:
- `build.lib.entry`: `path.resolve(dirname, 'src/index.ts')`
- `build.lib.formats`: `['es']` (ESM only — modern package, "type": "module" already set)
- `build.lib.fileName`: `'truf-design-system'`
- `build.rollupOptions.external`: `['react', 'react-dom', 'react/jsx-runtime', '@vis.gl/react-google-maps']` — these are peer deps, not bundled
- `build.rollupOptions.output.globals`: not needed for ES format
- `build.cssFileName`: `'styles'` — produces dist/styles.css
- `build.rollupOptions.output.preserveModules`: false (single bundle is fine for this size)

Important: The tailwindcss vite plugin must remain in plugins so CSS is processed during build. Do NOT remove it.
  </action>
  <verify>
Run `npx tsc --project tsconfig.lib.json --noEmit` to verify the lib tsconfig parses correctly with no errors. Then run `npm run build` and confirm dist/ directory is created with a .js file and styles.css.
  </verify>
  <done>src/index.ts exports all 16 components and 7 type exports. tsconfig.lib.json exists for declaration emit. vite.config.ts has build.lib config. `npm run build` produces dist/ with JS bundle and CSS.</done>

8. **exports**: Add exports map:
```json
"exports": {
  ".": {
    "import": "./dist/truf-design-system.js",
    "types": "./dist/index.d.ts"

  "./styles": "./dist/styles.css",
  "./styles.css": "./dist/styles.css"
}
```
9. **files**: `["dist", "README.md"]` — controls what gets published
10. **peerDependencies**: Add:

```json
}
```
