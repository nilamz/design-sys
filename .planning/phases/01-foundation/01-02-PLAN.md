  <action>
    Replace the placeholder `src/styles/globals.css` with the full implementation. The file must follow this exact order (import order matters for variable resolution):

    1. **`@import "tailwindcss";`** — Tailwind v4 entry point (NOT @tailwind directives)

    2. **`@import "../tokens/index.css";`** — Load all token CSS custom properties before @theme references them

    3. **`@theme inline { ... }`** block — Maps --truf-* tokens to Tailwind utilities. Use `@theme inline` (not just `@theme`) because all values reference CSS variables via `var()`. This block should:
       - Clear default colors: `--color-*: initial;`
       - Map all forest scale: `--color-forest-50: var(--truf-forest-50);` through `--color-forest-900`
       - Map all lime scale: `--color-lime-50: var(--truf-lime-50);` through `--color-lime-900`
       - Map all mint scale: `--color-mint-50: var(--truf-mint-50);` through `--color-mint-400`
       - Map all neutral scale: `--color-neutral-50: var(--truf-neutral-50);` through `--color-neutral-950`
       - Map cream: `--color-cream: var(--truf-cream);`
       - Map semantic colors: `--color-success: var(--truf-success);` etc.
       - Map font families: `--font-sans: var(--truf-font-sans);`, `--font-mono: var(--truf-font-mono);`, `--font-display: var(--truf-font-display);`
       - Map radii: `--radius-sm: var(--truf-radius-sm);` through `--radius-full`
       - Map shadows: `--shadow-xs: var(--truf-shadow-xs);` through `--shadow-glow`
       - Map spacing (use Tailwind's spacing namespace): `--spacing-1: var(--truf-space-1);` through `--spacing-24`
       This generates Tailwind utility classes like `bg-forest-500`, `text-lime-400`, `rounded-pill`, `shadow-glow`, `font-display`, etc.

    4. **`:root { ... }`** block — Dark theme semantic aliases (dark is default):
       ```
       --bg: var(--truf-neutral-950);
       --surface: var(--truf-neutral-900);
       --surface-elevated: var(--truf-neutral-800);
       --text-primary: var(--truf-neutral-50);
       --text-secondary: var(--truf-neutral-400);
       --text-muted: var(--truf-neutral-500);
       --border: var(--truf-neutral-700);
       --accent: var(--truf-lime-400);
       --accent-hover: var(--truf-lime-500);
       ```

    5. **`[data-theme="light"] { ... }`** block — Light theme overrides:
       ```
       --bg: var(--truf-neutral-50);
       --surface: #ffffff;
       --surface-elevated: var(--truf-neutral-100);
       --text-primary: var(--truf-neutral-900);
       --text-secondary: var(--truf-neutral-600);
       --text-muted: var(--truf-neutral-500);
       --border: var(--truf-neutral-200);
       --accent: var(--truf-forest-600);
       --accent-hover: var(--truf-forest-700);
       ```

    6. Add base body styles using semantic aliases:
       ```css
       body {
         background-color: var(--bg);
         color: var(--text-primary);
         font-family: var(--truf-font-sans);
       }
       ```
