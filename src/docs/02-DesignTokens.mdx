## Typography

Truf pairs a **characterful display serif** (Fraunces, variable axes) with a **clean editorial sans** (Inter, for UI and body) and a precise **monospace** (JetBrains Mono, for data, tokens, and technical labels).

| Role | Font | Size | Weight | Line Height |
|------|------|------|--------|-------------|
| Display / H1 | Fraunces | 60px | 400 | 1.02 |
| H2 | Fraunces | 48px | 400 | 1.1 |
| H3 | Fraunces | 30px | 500 | 1.2 |
| H4 / Subhead | Inter | 20px | 600 | 1.3 |
| Body / Lead | Inter | 18px | 400 | 1.55 |
| Body / Base | Inter | 16px | 400 | 1.6 |
| Caption | Inter | 12px | 400 | 1.5 |
| Mono / Label | JetBrains Mono | 11px | 500 | 1.5 |

## Z-Index Layers

| Token | Value | Use Case |
|-------|-------|----------|
| `z.base` | 1 | Default stacking context |
| `z.sticky` | 100 | Sticky headers, side navs |
| `z.drawer` | 200 | Drawers, side panels |
| `z.modal` | 400 | Modals, dialogs |
| `z.toast` | 600 | Snackbars, notifications |
| `z.tooltip` | 800 | Tooltips, popovers |
