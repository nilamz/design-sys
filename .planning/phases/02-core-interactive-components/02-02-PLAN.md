**2. Create `src/components/Switch/Switch.tsx`:**
- Props interface: `checked: boolean`, `onChange: (checked: boolean) => void`, `label?: string`, `disabled?: boolean`
- Structure: `<label>` wrapper with `className="relative inline-block w-[44px] h-[24px]"`. Inside: hidden `<input type="checkbox" className="sr-only">` bound to checked/onChange, then `<span>` with className that conditionally includes `switch-checked` when checked. The span gets class `switch-slider`.
- Accessibility: The `<input>` element provides keyboard and screen reader support. Add `aria-label` from label prop if provided, or render label text as `<span className="sr-only">`.
- Disabled: add `opacity-50 cursor-not-allowed` to wrapper, pass `disabled` to input.
- The outer label applies `switch-checked` class conditionally: `className={\`relative inline-block w-[44px] h-[24px] ${checked ? 'switch-checked' : ''} ${disabled ? 'opacity-50 cursor-not-allowed' : ''}\`}`
- Export as named export `Switch`

**3. Create `src/components/Checkbox/Checkbox.tsx`:**
- Props interface: `checked: boolean`, `onChange: (checked: boolean) => void`, `label?: string`, `disabled?: boolean`
- Structure: `<label className="inline-flex items-center gap-2 cursor-pointer">` containing hidden `<input type="checkbox" className="sr-only">` and a visual `<span>` with conditional classes.
- Visual span classes: always `w-[18px] h-[18px] border-2 rounded-[4px] inline-grid place-items-center` + transition. When checked: `bg-lime-500 border-lime-500 checkbox-checked`. When unchecked: `border-[var(--border-strong)] bg-transparent`. Use style prop for border-color on unchecked: `style={{ borderColor: 'var(--border-strong)' }}`.
- Transition: add `style` with `transition: 'all var(--truf-duration-fast)'` on the visual span.
- Label text: `{label && <span className="text-sm" style={{ color: 'var(--text-primary)' }}>{label}</span>}`
- Export as named export `Checkbox`

**4. Create `src/components/Tabs/Tabs.tsx`:**
- Types: `interface Tab { id: string; label: string; }`, `interface TabsProps { tabs: Tab[]; activeTab: string; onTabChange: (id: string) => void; }`
- Container: `<div className="flex border-b gap-4" style={{ borderColor: 'var(--border)' }}>`
- Each tab: `<button>` with onClick calling `onTabChange(tab.id)`. Classes: `px-2 py-3 text-sm cursor-pointer border-b-2 mb-[-1px]` + conditional: active = `text-lime-400 border-lime-500`; inactive = `border-transparent hover:text-[var(--text-primary)]` with `style={{ color: 'var(--text-muted)' }}` for inactive text.
- Transition on each button: `style` includes `transition: 'all var(--truf-duration-fast)'`
- The `-1px` bottom margin is CRITICAL — it makes the active indicator overlap the container border.
- Export both `Tabs` and the `Tab` type.

**5. Create `index.ts`** barrel files for each: `export { Switch } from './Switch';`, `export { Checkbox } from './Checkbox';`, `export { Tabs } from './Tabs';` (also export `Tab` type from Tabs index).
