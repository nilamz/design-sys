**3. Create `src/components/Button/Button.tsx`** — Follow the RESEARCH.md code example closely. Key requirements:
- Props: `variant` ('contained' | 'outlined' | 'text', default 'contained'), `size` ('sm' | 'md' | 'lg', default 'md'), `disabled`, `children`, extends `ButtonHTMLAttributes<HTMLButtonElement>`
- Variant classes: contained = `bg-lime-500 text-forest-900 font-semibold hover:bg-lime-400 hover:shadow-glow active:translate-y-px`; outlined = `bg-transparent border border-[var(--border-strong)] hover:border-lime-500 hover:text-lime-400` with `style={{ color: 'var(--text-primary)' }}`; text = `bg-transparent text-lime-400 hover:bg-[rgba(45,214,83,0.08)]`
- Size classes: sm = `py-1.5 px-3.5 text-xs`; md = `py-2.5 px-5 text-sm`; lg = `py-3.5 px-7 text-base`
- Base classes: `font-sans font-medium rounded-pill border border-transparent cursor-pointer inline-flex items-center gap-2 tracking-[-0.005em]`
- Disabled: `opacity-40 cursor-not-allowed pointer-events-none`
- Focus: `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-lime-500`
- Transition via style prop: `transition: 'all var(--truf-duration-fast) var(--truf-ease-standard)'`
- Export as named export `Button`
