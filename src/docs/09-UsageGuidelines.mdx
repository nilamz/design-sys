## Color

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: '0.75rem', marginTop: '1.5rem' }}>
  <DoCard>Use lime as a single, decisive accent per view — the one CTA, the one active state, the one highlight word.</DoCard>
  <DontCard>Don't distribute lime evenly across multiple elements. It loses impact and becomes visual noise.</DontCard>
</div>

## Typography

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: '0.75rem', marginTop: '1.5rem' }}>
  <DoCard>Pair the Fraunces italic with roman in the same heading to create rhythm and emphasize meaning.</DoCard>
  <DontCard>Don't set body copy in Fraunces — it's a display face. Body always uses Inter.</DontCard>
</div>

## Iconography

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: '0.75rem', marginTop: '1.5rem' }}>
  <DoCard>Use the scan-bracket icons for Truf product features (Facematch, Liveness, Hub, User).</DoCard>
  <DontCard>Don't mix icon sets. For generic UI needs, stay consistent with 2px outline Material Icons.</DontCard>
</div>
