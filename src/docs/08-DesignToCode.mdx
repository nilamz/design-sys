## The `sx` Prop — Inline Theme Access

```tsx
// Instead of this (brittle, untyped):
<Box style={{ padding: '16px', background: '#2DD653' }}>

// Do this (token-driven, typed, theme-aware):
<Box sx={{
  p: 4,                        // theme.spacing(4) = 16px
  bgcolor: 'secondary.main',   // theme.palette.secondary.main
  color: 'primary.main',
  borderRadius: 'pill',
  '&:hover': { bgcolor: 'secondary.light' },
}}>
```
