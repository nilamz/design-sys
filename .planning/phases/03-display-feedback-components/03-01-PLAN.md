    **Badge component (Badge.tsx):**
    - Type `BadgeVariant = 'lime' | 'forest' | 'mint' | 'outline'`
    - `variantClasses` Record mapping: lime = `bg-lime-500 text-forest-900`, forest = `bg-forest-600 text-cream`, mint = `bg-mint-200 text-forest-900`, outline = empty string (text via inline style)
    - Props: `variant` (default 'lime'), `children`, `className`, `style`, rest spread on span
    - Render as `<span>` with shared classes: `inline-flex items-center px-2.5 py-0.5 text-xs font-mono rounded-pill`
    - Outline variant: add `border` class, inline style `borderColor: 'var(--border-strong)'`, text color via `style={{ color: 'var(--text-primary)' }}`
    - Follow Button.tsx pattern: filter(Boolean).join(' ') for className, spread style prop

    **Badge stories (Badge.stories.tsx):**
    - Meta: title 'Components/Badge', tags ['autodocs'], layout 'centered'
    - Stories: Lime (default), Forest, Mint, Outline -- each with `args: { variant, children: 'Badge' }`
    - No useState needed (stateless component)

    **Badge test (Badge.test.tsx):**
    - Use createRoot + DOM assertion pattern (see Phase 2 tests)
    - Test: renders with correct text content
    - Test: lime variant has bg-lime-500 class
    - Test: outline variant has border class
    - Test: applies pill radius class (rounded-pill)

    **Chip component (Chip.tsx):**
    - Props: `active` (boolean, default false), `children`, `onClick`, `className`, `style`, rest spread on button
    - Active state: `bg-lime-500 text-forest-900`, Inactive state: `text-forest-900` with inline style `background: 'var(--surface-2)'`
    - Shared classes: `rounded-pill cursor-pointer font-sans text-sm font-medium px-4 py-1.5 border-0`
    - Render as `<button>` element (semantically clickable)
    - Transition via inline style: `transition: all var(--truf-duration-fast) var(--truf-ease-standard)`

    **Chip stories (Chip.stories.tsx):**
    - Meta: title 'Components/Chip', tags ['autodocs'], layout 'centered'
    - Stories: Active, Inactive, ChipGroup (render multiple chips showing toggle behavior with useState)

    **Chip test (Chip.test.tsx):**
    - Test: renders with correct text
    - Test: active chip has bg-lime-500 class
    - Test: inactive chip does not have bg-lime-500
    - Test: renders as button element

    **index.ts** for both: `export { Badge } from './Badge'` / `export { Chip } from './Chip'`

  <action>
    **Alert component (Alert.tsx):**
    - Type `AlertVariant = 'success' | 'warning' | 'error' | 'info'`
    - `variantConfig` Record mapping each variant to `{ color: string, bg: string }`:
      - success: `{ color: 'var(--truf-success)', bg: 'rgba(34, 176, 64, 0.08)' }`
      - warning: `{ color: 'var(--truf-warning)', bg: 'rgba(230, 168, 23, 0.08)' }`
      - error: `{ color: 'var(--truf-error)', bg: 'rgba(220, 75, 63, 0.08)' }`
      - info: `{ color: 'var(--truf-info)', bg: 'rgba(43, 125, 214, 0.08)' }`
    - Props: `variant` (default 'info'), `title` (optional string), `description` (optional string), `children` (optional ReactNode), `className`, `style`
    - Render as `<div>` with className: `border-0 border-l-4 border-solid rounded-sm p-4`
    - Inline style: `borderLeftColor: variantConfig[variant].color`, `background: variantConfig[variant].bg`
    - If `title`: render `<strong>` with `className="block mb-1 text-sm font-semibold"` and `style={{ color: 'var(--text-primary)' }}`
    - If `description`: render `<p>` with `className="text-sm m-0"` and `style={{ color: 'var(--text-secondary)' }}`
    - If `children`: render children (allows custom content)
    - IMPORTANT: Use `border-0 border-l-4 border-solid` to prevent Tailwind border utility from applying color to all sides (Pitfall 4 from research)

    **Alert stories (Alert.stories.tsx):**
    - Meta: title 'Components/Alert', tags ['autodocs'], layout 'padded'
    - Stories: Success, Warning, Error, Info -- each with `args: { variant, title: 'Alert Title', description: 'Description text here.' }`
    - Story: WithChildren -- passes custom JSX as children

    **Alert test (Alert.test.tsx):**
    - Test: renders with title text
    - Test: renders with description text
    - Test: has border-l-4 class
    - Test: success variant has correct borderLeftColor inline style

    **index.ts:** `export { Alert } from './Alert'`
