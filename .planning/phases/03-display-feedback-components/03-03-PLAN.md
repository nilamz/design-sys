    - Props: `amount` (number), `currency` (string, default '$'), `surgeMultiplier` (optional number), `breakdown` (FareBreakdown), `className` (optional)
    - Render structure:
      1. Wrap everything in `<Card className={className}>`
      2. Header row: flex container with fare amount and optional surge badge
         - Amount: `<span className="font-display text-4xl font-bold" style={{ color: 'var(--text-primary)' }}>{currency}{amount.toFixed(2)}</span>`

         - Each row: `<div className="flex justify-between py-1.5">` containing `<dt>` (label) and `<dd>` (value formatted as currency)
         - Items: Base fare, Distance, Time, Surge (only if > 0), Total (bold/separator)

    **RideMap component (RideMap.tsx):**
    - Import `{ APIProvider, Map, AdvancedMarker, Pin }` from '@vis.gl/react-google-maps'
    - Note: Polyline may not be directly exported. Check the library. If not available as a direct component, use `useMap` hook to draw polyline via Google Maps JS API, OR use a simple straight-line approach. The research suggested Polyline as a component but validate at implementation time.
    - Interface `LatLng`: `{ lat: number; lng: number }`
    - Props: `apiKey` (string), `pickup` (LatLng), `dropoff` (LatLng), `driver` (optional LatLng), `className` (optional)
    - Calculate center: `{ lat: (pickup.lat + dropoff.lat) / 2, lng: (pickup.lng + dropoff.lng) / 2 }`
    - If `!apiKey`: render a placeholder div with the same Truf container styling showing "Map requires API key" message, so Storybook works without a key
    - Outer container div: `className` includes `rounded-lg overflow-hidden border shadow-md` + passed className, inline style: `borderColor: 'var(--border)', height: '320px', width: '100%'`
    - Inside: `<APIProvider apiKey={apiKey}>` wrapping `<Map defaultCenter={center} defaultZoom={13} mapId="truf-ride-map">`
    - Pickup marker: `<AdvancedMarker position={pickup}>` with `<Pin background="#2DD653" borderColor="#061A13" glyphColor="#061A13" />`
    - Dropoff marker: same pattern
    - Driver marker (conditional): same but with `background="#34E06A"` (slightly different lime shade)
    - IMPORTANT: Use hardcoded hex values for Pin props, NOT CSS vars (Pitfall 3 -- Google Maps JS API cannot read CSS custom properties)
    - For the polyline: if `@vis.gl/react-google-maps` does not export a Polyline component, create a small inner component that uses `useMap()` hook and `google.maps.Polyline` directly in a useEffect. StrokeColor: "#2DD653", strokeWeight: 3, strokeOpacity: 0.85.
